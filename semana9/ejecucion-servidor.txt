Al ejecutar `node server.js` se inicia el proceso de Node.js que carga la aplicación Express.
En la terminal aparece el mensaje: "Servidor ejecutándose en puerto 3000".
La terminal queda ocupada mientras el servidor se está ejecutando. Si se detiene el proceso, el servidor deja de estar disponible.

Al visitar `http://localhost:3000/` se muestra el texto:
Servidor activo y funcionando

Al visitar `http://localhost:3000/estado` se recibe el siguiente JSON:
{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
